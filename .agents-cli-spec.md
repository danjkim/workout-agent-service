# Agent Spec: Workout Routine Designer with Human-in-the-Loop Coach Prompt

## Overview
An AI agent that designs a user's workout routine for the day based on their desired focus area (e.g., chest, legs, arms, core, cardio, full body).
- **Instant Approval**: If the designed routine does not include heavy compound lifts (specifically **bench press**, **squats**, or **deadlifts**), the workout routine is instantly approved and presented to the user.
- **Human-in-the-Loop (HITL) Pause**: If the workout routine requires **bench press**, **squats**, or **deadlifts**, the agent triggers a human-in-the-loop pause prompting the user whether they want to work with a coach for form, spotting, and safety. Upon user confirmation, the workout routine is finalized according to the coach decision.

## Language
`python` (using google-adk)

## Example Use Cases
1. **User asks for an arms workout** (bicep curls, tricep extensions):
   - Routine contains no bench press, squats, or deadlifts.
   - Outcome: Instantly approved routine returned immediately.
2. **User asks for a leg day or heavy chest routine** (includes barbell squats or bench press):
   - Routine contains squats or bench press.
   - Outcome: Triggers a human-in-the-loop pause (`adk_request_confirmation`) asking whether the user wants to work with a coach before proceeding.

## Tools Required
- `submit_workout_routine`: Evaluates the proposed routine for compound lifts (`bench press`, `squats`, `deadlifts`). If found, invokes `tool_context.request_confirmation` to pause and prompt the user about coach assistance; otherwise immediately approves the routine.

## Constraints & Safety Rules
- Preserves safety guardrails for heavy compound lifts (bench press, squats, deadlifts).
- The root agent name matches `workout_agent_service` per `agents-cli-manifest.yaml`.
- App is configured with `ResumabilityConfig(is_resumable=True)` to support pause and resume.
- Model is preserved as `gemini-3.8-flash`.

## Success Criteria
- Instant approval path works end-to-end without pause when no compound lifts are present.
- Pause triggers correctly when bench press, squats, or deadlifts are present.
- Session can resume with user decision.
